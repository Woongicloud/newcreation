# 리허설 체크리스트

배포가 끝난 뒤, 행사 전에 실제 기기로 한 번 돌려보는 순서. 30분 정도 걸린다.
준비물: 관리자 PC, 프로젝터(또는 두 번째 화면), 진행자 폰 1대, 참가자 폰 2–3대.

## 0. 서버 상태 (1분)

- [ ] `https://서버주소/api/health` → `"storage":"supabase"`, `"database":"ok"`
  - `"database":"error"`면 함께 나오는 `databaseError`가 원인이다
  - `"storage":"memory"`면 Railway에 `SUPABASE_URL` / `SUPABASE_SERVICE_KEY`가 없다

## 1. 자동 점검 (선택, 2분)

PC에 리포가 있으면 가상 참가자로 배포된 서버에 한 판을 돌려볼 수 있다. Supabase 저장까지 실제로 거친다.

```bash
TARGET=https://서버주소 ADMIN_PASSWORD=비밀번호 PLAYERS=30 npm run loadtest
```

- [ ] 끝까지 돌고 `저장소 supabase · database ok`가 찍힌다
- [ ] "상태 전파" 최대값이 1초 미만이다 (행사장 와이파이가 아니라 서버 자체의 속도)

테스트로 만든 방은 스크립트가 닫는다.

## 2. 준비 (관리자 PC)

- [ ] `/admin` 로그인
- [ ] 새 방 → `sample_quiz_set_v2.json`(또는 행사용 세트) 올리기 → "적용됨"과 라운드·문제·학년 수 확인
- [ ] Supabase Table Editor의 `sessions`에 방이 생겼다
- [ ] 진행자 QR 만들기

## 3. 접속

- [ ] 프로젝터 PC에서 Display 주소 열기 → 전체화면 → QR과 방 코드가 보인다
- [ ] 진행자 폰으로 진행자 QR → "게임 시작" 버튼이 보인다
- [ ] 참가자 폰으로 Display의 QR → 이름 + 학년 + 브릿지 → "입장 완료"
- [ ] Display에 입장한 이름이 뜨고, 관리자 **② 진행** 탭에 참가자가 보인다

## 4. 진행 (진행자 폰)

- [ ] 게임 시작 → 문제 시작 → 참가자가 답 제출 → 폰에는 고른 답만 눌린 채 고정되고, 정답·점수는 아직 안 보인다
- [ ] Display의 제출 수가 올라가고, 전원 제출하면 "마감!"
- [ ] 정답 공개 → Display에 큰 정답 카드와 보기별 인원, 참가자 폰에 이번 문제 점수가 떠오른다
- [ ] `개인 집계` → Display에 `등수 · 학년 · 브릿지 · 이름 · 점수`, 참가자 폰에 내 순위
- [ ] 문제 진행 중 `일시정지` / `재개`, `+10초`
- [ ] 관리자 PC의 진행 탭에서도 "다음"을 눌러본다 — 폰과 PC가 같은 화면을 따라간다
- [ ] 채팅을 보내면 Display에 흐른다

## 5. 끊김 대비

- [ ] 참가자 폰에서 새로고침 → 같은 점수로 이어진다
- [ ] 참가자 폰을 비행기 모드로 5초 → 해제 → "연결이 끊겼습니다" 띠가 사라지고 이어진다
- [ ] 진행자 폰 화면을 껐다 켠다 → 버튼이 현재 단계에 맞게 나온다
- [ ] 문제 진행 중 Railway에서 **Restart** → 1분 안에 모든 화면이 같은 문제로 돌아온다

## 6. 표시 설정 (관리자 PC ③)

- [ ] 채팅 글자 크기 슬라이더 → Display에서 바로 커진다
- [ ] 테마 변경 → Display 색이 바뀐다
- [ ] 배경 이미지 올리기 → Display 배경이 바뀐다 (Supabase Storage를 처음 쓰는 지점)
- [ ] 프로젝터에서 글자가 뒤쪽 자리에서도 읽히는지 확인

## 7. 시상

- [ ] 마지막 라운드까지 진행 → "게임 종료 · 시상 준비"
- [ ] 관리자 **④ 시상** 탭에 항목별 결과가 미리 보인다 (필요하면 순서·연출 변경 후 저장)
- [ ] 다음 시상 → 공개 → … 브릿지 순위, 행운상(슬롯), 개인 순위, 뉴평 중간값
- [ ] `더보기 → 메인 화면 띄우기` → Display가 행사 이름 화면으로 돌아간다

## 8. 마무리

- [ ] 관리자 **① 준비**에서 리허설 방 닫기
- [ ] 행사용 문제 세트를 올려 "적용됨"이 뜨는지 미리 확인해 둔다 (오류가 있으면 위치를 알려준다)

## 행사 당일 메모

- 세트를 올려야 참가자 QR이 나온다. 방 만들기 → 세트 올리기를 입장 전에 끝낸다.
- 진행자 QR은 24시간 유효하다. 당일에 새로 만든다.
- 진행자 폰은 충전기에 꽂아 두고, 화면 자동 잠금이 걸려도 다시 켜면 이어진다.
- 문제가 생기면 관리자 PC의 진행 탭으로 그대로 진행할 수 있다.
